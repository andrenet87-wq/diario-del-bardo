# Pubblicare Diario del Bardo

Il progetto è un sito statico: non richiede database o backend.

## GitHub Pages
1. Crea un repository, ad esempio `diario-del-bardo`.
2. Carica **il contenuto della cartella `Diario_del_Bardo_v0.19.0`** nella root del repository.
3. In GitHub apri **Settings → Pages**.
4. In **Build and deployment** scegli **Deploy from a branch**.
5. Scegli `main` e cartella `/ (root)`, poi salva.
6. GitHub mostrerà il link pubblico appena il deploy termina.

### Nota
Il Diario continua a funzionare anche offline aprendo `index.html`. Per una versione pubblica ai giocatori conviene in futuro introdurre un filtro che nasconda Sessione, Asset Bible, Produzione e teorie private.
